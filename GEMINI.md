# Quy tắc phát triển (Development Rules)

- **Không tự động chạy lệnh `npx`, `npm install`, `ng new`, hay các lệnh tạo/cài đặt dự án mới** trừ khi người dùng yêu cầu cụ thể.
- **Chỉ sửa đổi và cập nhật mã nguồn (code) trực tiếp** trong cấu trúc thư mục hiện tại của dự án.
- Tập trung chỉnh sửa code hiện có hoặc tạo các file code mới trực tiếp thay vì chạy các lệnh thiết lập môi trường hay cài đặt package mới.

---

- **Do not automatically run `npx`, `npm install`, `ng new`, or any project creation/installation commands** unless explicitly requested by the user.
- **Only modify and update the source code directly** within the existing workspace directory structure.
- Focus on editing existing code or creating new code files directly rather than running commands to set up new environments or install packages.
